# UMBE-LAB website
A static GitHub Pages homepage. There is no build step and no external JavaScript, dependency, or analytics. Open index.html directly in a browser, even offline. Both original figures are embedded; no assets folder is needed.

## Publish under UMBE-LAB
1. Sign in to GitHub as an organization member with repository and Pages permissions. Check whether UMBE-LAB/umbe-lab.github.io already exists. Do not replace an existing site without first inspecting its contents and settings.
2. If it does not exist, create a public repository named umbe-lab.github.io with UMBE-LAB as owner. Extract the ZIP and commit index.html and .nojekyll at the repository root on main. README.md is optional.
3. In Settings > Pages select Deploy from a branch, then main and / (root), and save. Verify the deployment and open https://umbe-lab.github.io/ in a signed-out browser before changing the Concordia profile link.
4. Leave the existing project repositories and custom domains unchanged. No CNAME is included in this package. Once the new URL is verified, change the faculty profile's Personal Website link separately.

The CityFFD interactive demo can be featured on the CityFFD card once a stable public URL has been confirmed. Until then the card links to the lab's public dataset instead.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
